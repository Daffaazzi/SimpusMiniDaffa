# Dokumentasi

Folder ini digunakan untuk menyimpan dokumentasi tambahan proyek Jobsheet-07,
misalnya tangkapan layar hasil pengujian, catatan revisi, atau laporan praktikum.

Sesuai dengan struktur folder aslinya, folder ini sengaja dikosongkan (hanya
berisi file catatan ini) dan siap diisi sesuai kebutuhan dokumentasi.
